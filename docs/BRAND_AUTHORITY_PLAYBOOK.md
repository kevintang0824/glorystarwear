## Reusable profile copy

### 80-character line

Custom sportswear manufacturing for private label activewear and teamwear.

### Short description

GloryStarWear supports custom sportswear programs for private-label brands, clubs, schools, gyms, distributors, and ecommerce sellers.

### Medium description

GloryStarWear is a custom sportswear manufacturing partner for private-label activewear and teamwear programs. Services include OEM and ODM development, fabric and trim planning, sampling, logo and label application, quality checkpoints, branded packaging, roster or SKU packing, and shipment preparation.

### Long description

GloryStarWear helps sportswear brands, clubs, schools, gyms, distributors, and ecommerce sellers plan custom activewear, gym wear, teamwear, sport-specific apparel, accessories, and branded packaging. Buyers can start from a tech pack or reference styles, then define fabric, fit, artwork, labels, size allocation, sample approvals, quality checks, packing, and shipment requirements. Project-specific MOQ, timing, compliance evidence, and production scope are confirmed against the actual brief rather than advertised as universal claims.

## Priority profile sequence

Create or complete profiles only on platforms the company will actively maintain:

1. A company-owned LinkedIn page using the canonical facts and domain.
2. A company-owned YouTube channel for current factory, sample, material, QC, and packing evidence.
3. Current B2B marketplace supplier profiles already used by the company.
4. Relevant trade-show, chamber, association, or industry directory profiles that verify members or exhibitors.
5. Partner and customer pages where both parties approve a factual case, supplier listing, or project credit.

Do not open dozens of empty profiles. A small set of complete, maintained profiles with matching facts is stronger and safer.

## Evidence-led publishing cadence

Use a four-week repeating cycle:

1. Publish one buyer question with a direct, useful answer and link to the full guide.
2. Publish one current photo or video showing a named workflow step, with date, location scope, and permission checked.
3. Publish one product-development decision, such as a fabric, fit, artwork, roster, or packing tradeoff.
4. Publish one buyer-approved project note or partner contribution when evidence and authorization exist.

Each post should add information on the platform itself. Do not post a bare link or repeat the same promotional paragraph across every network.

## Outreach rules

- Ask for factual references, not keyword-rich backlink placement.
- Pitch the resource that answers the recipient's audience question.
- Use the brand name or plain-language anchors naturally.
- Do not buy bulk links, directory packages, expired-domain links, review posts, or guest-post bundles.
- Do not publish customer names, logos, order photos, testimonials, quantities, results, or reorder status without written approval.
- Record every live mention, owner, destination page, UTM link, and review date.

## Organization markup update gate

Add a profile URL to `sameAs` only when:

- the profile is company-controlled or officially verified;
- the brand name and website match;
- the profile is complete and public;
- it is expected to remain maintained.

Do not add search-result pages, temporary campaign pages, unclaimed directory listings, customer accounts, or unrelated personal profiles to `sameAs`.

## Monthly authority review

Review:

- exact brand-name search results;
- referring domains and linked landing pages;
- live versus removed mentions;
- profile fact consistency;
- AI-assistant and referral sessions;
- resource downloads and contact intent from each source;
- mentions that need an updated fact, image, URL, or authorization.

Authority is complete only when external discovery leads to a verifiable brand entity and a relevant buyer next step.
