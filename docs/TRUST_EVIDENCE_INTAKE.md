# GloryStarWear 真实信任证据收集表

更新时间：2026-08-21

## 当前结论

网站项目目录内未发现可以直接公开验证的营业执照、公司注册资料、工厂实拍、工厂视频、审厂报告、证书 PDF、客户授权评价或真实项目案例表。

现有工厂、质检、包装和案例图片来自网站的生成式视觉素材，只能用于产品或流程说明，不能标注为工厂实拍、客户订单、审厂证据或交付成果。

## 网站披露状态

- `factory-video.html` 已明确披露当前四张图片均为示意视觉，且当前页面未发布可核验的 GloryStarWear 工厂实拍或视频。
- `sportswear-manufacturer.html` 已将四张图片标为示意视觉，并将页面限定为拟议 OEM、ODM、轻定制或混合路线的询盘、责任交接和证据比较方法；页面本身不证明工厂身份、所有权、产能、当前可用性或项目可行性。
- 在收到注明主体、站点、拍摄日期、工序、授权和公开范围的真实资料前，不得把示意素材或媒体请求写成已有工厂证据或固定视频通话能力。
- 收到资料后，先使用工厂媒体核验表记录来源、范围、连续性、脱敏、授权、审核人和局限，再决定是否公开替换页面素材。

## 第一批最低上线资料

请优先收集以下四组资料。每项都需要注明是否允许公开、是否需要脱敏，以及资料负责人。

### 1. 公司主体

- 中文法定名称
- 英文法定名称
- 成立年份
- 统一社会信用代码或注册编号
- 注册国家、省市和可公开地址
- 品牌与法律主体的关系
- 联系人姓名、职位和公司邮箱
- 可公开的营业执照或官方查询链接

不要在公开页面写入没有文件支持的成立年份、地址、员工数、面积、产能或出口国家数量。

### 2. 工厂与生产媒体

第一批建议提供 8–12 张横版原图和一条 60–90 秒视频：

| 文件 | 应展示内容 | 必填说明 |
| --- | --- | --- |
| 01-building | 门头、厂名或园区环境 | 拍摄日期、城市、工厂主体 |
| 02-sample-room | 样品室或开发区 | 拍摄日期、负责人 |
| 03-fabric | 面料、色卡或来料检查 | 对应工序 |
| 04-cutting | 裁床或裁剪流程 | 对应工序 |
| 05-sewing | 真实车缝线 | 对应产品 |
| 06-printing | 印花、热转印、刺绣或升华 | 工艺名称 |
| 07-inspection | 尺寸、外观或功能检查 | 检验点 |
| 08-packing | 标签、包装、装箱或出货 | 对应项目 |

原图应保留拍摄时间和原始分辨率。若画面包含客户 Logo、订单号、员工正脸、电话号码或地址，先确认授权或脱敏。

### 3. 证书、审厂与测试

每份公开资料记录：

- 文件名称
- 持证主体
- 签发机构
- 证书或报告编号
- 适用工厂、产品、材料或流程
- 签发日期和有效期
- 官方核验链接或核验方式
- 公开完整版、脱敏版或仅向合格买家提供

证书必须与实际接单主体、生产工厂或材料供应范围对应。供应商材料证书不能写成 GloryStarWear 自有证书。

### 4. 三个真实项目案例

每个案例至少填写：

- 客户类型和地区
- 产品类别和款式数量
- 订单数量或可公开区间
- 定制内容
- 打样次数和关键修改
- 样品周期和大货周期
- 质量检查方式
- 包装和交付方式
- 最终结果
- 是否返单
- 可公开照片、视频、评价或链接
- 客户授权范围

匿名案例也必须来自真实项目。匿名只隐藏身份，不能省略事实核验。

## 发布前检查

- 页面文字与文件中的主体、日期、范围一致。
- 图片明确区分“实拍”“客户授权”“示意图”。
- 删除或遮挡个人身份证号、银行信息、私人电话、签名和客户机密。
- 证书未过期，并提供核验方法。
- 案例中的数量、周期、结果和返单信息有内部记录支持。
- 首页只展示最强的 3–5 项证据，并链接到完整证据页。
- Organization 和页面结构化数据只写入已验证、公开可见的信息。
- 资料过期、主体变化或授权撤回时及时下线。
