Sommaire/Confidentialité

Données d'enquête

Confidentialité et données de contact

Cette page explique ce qui arrive aux informations de recherche et comment les analyses optionnelles du site Web sont contrôlées.

Voies de contact actuelles

Comment votre demande est traitée

GloryStarWear est le nom commercial du site Web. L'entité juridique vérifiée et les coordonnées enregistrées seront ajoutées lorsque les dossiers de l'entreprise à l'appui seront approuvés pour publication.

WhatsApp

Lorsque vous choisissez WhatsApp, le site prépare votre mémoire de projet et ouvre WhatsApp. Le message n'est envoyé que lorsque vous le confirmez dans WhatsApp, dont les propres conditions de confidentialité s'appliquent.

Courriel

Lorsque vous choisissez email, le site prépare un message pour votre application email locale. Le site ne peut pas confirmer la livraison; les conditions de votre fournisseur de messagerie s'appliquent après l'avoir envoyé.

Formulaire de serveur sécurisé

Cette option utilise Cloudflare Turnstile pour réduire le spam automatisé, puis envoie le mémoire complété au même point d'arrivée Vercel. Vercel le valide et le transmet par une connexion authentifiée de serveur à serveur à une base de données dédiée de recherche Cloudflare D1. Une soumission réussie n'est affichée qu'après que la base de données confirme le stockage, puis le site ouvre la page Merci.

Copier le mémoire du projet

La copie utilise votre presse-papiers de navigateur. Le site Web ne traite pas un mémoire copié comme une demande reçue.

Fichiers de référence

Les fichiers sélectionnés dans le constructeur de devis restent sur votre appareil à moins que vous ne choisissions l'option -Share Brief + Files et sélectionnez une application de destination. Le serveur sécurisé enregistre uniquement les noms de fichiers sélectionnés; il ne télécharge pas ou ne stocke pas le contenu du fichier. WhatsApp et email vous obligent à joindre des fichiers dans ces applications. Évitez les renseignements personnels dans les noms de fichiers.

Champ des données

Informations utilisées pour votre demande

Nous demandons les détails minimums nécessaires pour comprendre un projet de sourcing et répondre par le biais de la route de contact que vous choisissez.

Personne à contacter

Nom, courriel de travail, téléphone optionnel ou WhatsApp

Utilisé pour identifier la personne qui fait la demande et y répondre.

Projet

Type d'acheteur, itinéraire, produit, quantité, marché, chronométrage, message et noms de fichiers sélectionnés

Utilisé pour évaluer la demande et préparer une réponse pertinente à l'approvisionnement. Le contenu du fichier n'est pas envoyé par le formulaire sécurisé.

Source

Page d'atterrissage, page de référence, étiquettes de campagne et catégorie de source

Entreposé dans un stockage de session et inclus dans une enquête préparée pour que l'équipe puisse comprendre si la conversation a commencé par la recherche, un assistant en AI, les médias sociaux, une campagne, un autre site Web ou une visite directe.

Analyse facultative

Visites de pages, source de trafic et actions sélectionnées sur le site

Google Analytics 4 ne charge que lorsque vous autorisez l'analyse. Le site peut ensuite mesurer les vues de page, les démarrages de devis, les choix de chemin acheteur, les demandes d'appel, les catégories de nombre de fichiers et de type de fichiers, les soumissions confirmées de serveur, les clics de contact, les téléchargements de ressources, les filtres de produits et les recherches de catalogue. Les événements analytiques ne comprennent pas les noms de fichiers, le contenu de fichiers, les noms de contacts, les adresses électroniques, les numéros de téléphone ou le texte du message.

Protection des personnes

Ne pas envoyer de documents sensibles ou confidentiels initialement

Évitez les données de paiement, les documents d'identité, les mots de passe ou les paquets technologiques confidentiels jusqu'à ce qu'une route d'échange protégée appropriée soit convenue.

Vos choix

Demandes d'accès, de correction, de conservation et de suppression

Personne à contacter kevin@glorystarwears.com demander des renseignements sur les demandes de renseignements, demander une correction ou demander la suppression, le cas échéant. Les dossiers d'enquête sous forme sécurisée doivent être supprimés 365 jours après leur réception. Un document peut être retiré plus tôt sur une demande valide ou conservé séparément lorsque cela est raisonnablement nécessaire pour une soumission active, une communication commerciale continue, une sécurité, un traitement des différends ou des obligations légales.

Tiers

Vercel héberge le site Web et valide les soumissions sous forme sécurisée. Les travailleurs Cloudflare et la base de données dédiée Cloudflare D1 reçoivent et conservent les demandes confirmées de formulaire de serveur. Une application de destination sélectionnée dans le menu de partage de votre appareil, WhatsApp, fournisseurs de messagerie et, seulement après l'autorisation d'analyse, Google Analytics peut traiter les données lorsque leur service est utilisé.

Choix de l'analytique

Le site stocke accordée ou refusé sous glorystarwear-analytics-consent-v1 Lorsque le navigateur est autorisé, Google Analytics peut utiliser des identifiants de première partie tels que _ga. Le stockage publicitaire, les données publicitaires des utilisateurs et la personnalisation de la publicité restent refusés.

Mises à jour

Cet avis sera mis à jour lorsque l'entité juridique, la plate-forme analytique, le CRM, le fournisseur de stockage, la période de conservation ou les changements de route de chargement de fichiers.

Personne à contacter

Les questions de confidentialité et d'enquête peuvent être envoyées au même courriel de contact d'entreprise affiché sur le site Web.
