Direct answer

What artwork files should you send to a sportswear manufacturer?

Send the original editable logo or artwork when available, plus a stable visual preview. True vector AI, EPS, SVG, or vector PDF files are commonly useful for scalable logos and separations. If the design is raster, provide the original high-resolution file at the intended output size rather than a screenshot. State the artwork revision, rights status, production method, finished dimensions, color reference, garment panel, placement reference, and approved sample or strike-off. The supplier should confirm method-specific production requirements after reviewing the actual artwork and substrate.

Track one row per artwork application

File decision

Choose the source file by what the artwork contains

A filename extension is not proof of usable production artwork. A PDF or SVG can still contain a low-resolution raster image, and placing a JPG inside an AI file does not make the image vector.

Authoritative format references

Verify the artwork, not only the extension

Adobe's file guidance explains that raster images are pixel-based while vector graphics use paths that can scale without the same resolution loss. Adobe also documents that outlining text turns it into vector shapes and removes ordinary text editing, so keep an editable source copy before outlining a release file.

Placement control

Define size and position from a repeatable reference

Descriptions such as “small left chest logo” or “move it slightly higher” cannot be audited. Record the finished dimensions, reference seam or panel, horizontal and vertical offsets, orientation, and the sample revision that proves the result.

  1. Assign the artwork ID

    Give every distinct application a stable code and include it in the tech pack, filename, placement sheet, sample comments, and approval register.

  2. State the finished output size

    Record width and height in one declared unit. If proportions must not change, say so; if the art varies by garment size, control each size rule explicitly.

  3. Use an identifiable origin

    Measure from a named seam, panel edge, center line, neckline point, label edge, or approved pattern reference instead of from an uncertain mockup boundary.

  4. Separate colorway and method variants

    Create separate controlled rows when artwork color, garment color, decoration method, substrate, dimensions, placement, or output file changes.

  5. Approve the physical result

    Link the released file to the strike-off, sew-out, transfer sample, patch sample, label proof, packaging proof, or garment sample actually reviewed.

  6. Freeze the bulk revision

    Record approver, date, decision, evidence, open exceptions, and the exact production file before bulk release.

FAQ

Sportswear logo and artwork file questions

Can I send a PNG logo to a sportswear manufacturer?

Yes for early review, and sometimes for a compatible raster production workflow, but send the original high-resolution file at the intended output size. A true vector source is usually more flexible for scalable logos, separations, and placement variants. The supplier should confirm the actual method-specific requirement.

Does saving a JPG as PDF make it vector?

No. A PDF can contain vector paths, raster images, or both. Changing the filename container does not recreate detail that is missing from the original pixel image.

Should fonts be converted to outlines?

A released vector file can use outlined text to reduce font dependency, but keep a separate editable source with live text. Outlining changes text into shapes, so ordinary text editing is no longer available in that copy.

Do I need a separate artwork record for every colorway?

Create a separate row whenever the artwork color, garment color, method, substrate, dimensions, placement, orientation, output file, or approval evidence changes. One row can cover multiple colorways only when every controlled artwork condition is genuinely identical.

Can the supplier use a team crest or sponsor logo found online?

Do not treat online availability as reproduction permission. The buyer should supply authorized artwork and confirm the right to use every logo, crest, sponsor mark, image, font, name, and licensed element.

Ready for artwork review?

Send the product brief and controlled source files together.

Include the style, colorway, quantity, garment or item, method, substrate, artwork IDs, dimensions, placements, rights confirmation, and sample stage.
