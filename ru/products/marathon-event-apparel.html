Может ли GloryStarWear сделать одежду для марафона?

GloryStarWear может делать футболки для марафона, синглеты, тисы для финишеров, футболки для волонтеров, носки, шапки, полотенца, этикетки и упаковку для мероприятий.

Могут ли рубашки включать в себя спонсорские работы?

Логотипы спонсоров, благотворительные знаки, названия мероприятий, даты гонок, знаки рукава, отпечатки спины, ярлыки на шее и хендтеги могут быть настроены.

Что должен прислать организатор мероприятия?

Отправьте список продуктов, дату мероприятия, количество, соотношение размеров, спонсорские работы, страну доставки, потребности в упаковке и любые правила маркировки склада.

Можно ли упаковать одежду для марафона по волнам событий или по размеру?

Заказы могут быть упакованы по размеру, волне событий, связке участников, группе спонсоров, команде добровольцев или товарам SKU.
